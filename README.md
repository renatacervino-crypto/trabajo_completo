# L'Élixir · Haute Parfumerie Paris
### Plataforma E-Commerce de Perfumes de Autor y Alta Gama

Bienvenido al repositorio oficial de **L'Élixir**, una experiencia de comercio electrónico editorial inspirada en las históricas casas de fragancias parisinas. El proyecto combina minimalismo refinado, alta jerarquía tipográfica y una cuidada arquitectura de diseño para una navegación inmersiva y de lujo.

---

## 🎨 Identidad Visual y Diseño Editorial

- **Tipografía:**
  - *Playfair Display:* Títulos y narrativa editorial de alto impacto visual.
  - *Plus Jakarta Sans:* Lectura neutral, especificaciones técnicas y micro-interacciones.
- **Paleta de Color:**
  - *Deep Onyx (`#1A1817`):* Tipografía principal, botones prioritarios y encuadres de contraste.
  - *Champagne Gold (`#C5A880`):* Detalles metálicos, micro-bordes y etiquetas olfativas.
  - *Antique Amber (`#9B7E51`):* Resaltados botánicos y estados activos.
  - *Warm Alabaster (`#FAF8F5`) & Ivory Stone (`#F5F2EB`):* Superficies suaves y cálidas estilo papel de archivo.

## 🚀 Cómo Visualizar el Proyecto

1. Clona o descarga este repositorio:
   ```bash
   git clone https://github.com/renatacervino-crypto/trabajo_completo.git
   ```
2. Abre el archivo [`index.html`](./index.html) en cualquier navegador web moderno (Chrome, Edge, Firefox, Safari).
3. Desde allí podrás ingresar y recorrer cada una de las 4 vistas interactivas completas.
